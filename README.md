# Desktop Doomsday · 桌面末世

> Windows 桌面常驻的**末日公路自动推进放置游戏**。开局选一辆车，车辆自动向前推进，宝箱开出物资，小人维持生存，随机副本可主动参与换取额外奖励——不参与也不影响基础推进。
>
> 它常驻在你的桌面上：半透明、置顶、可点击穿透，挂机时公路仍在跑。

---

## 一句话玩法

你不需要一直盯着它。选好车、让它上路，物资会自己进库存，小人会自己消耗与补给；偶尔桌面边缘弹出一行副本提示，想打就点、不想打就当它没出现。回归时看一眼离线报告，继续挂机。

---

## 核心循环

```
公路推进 tick → 里程累积 → 宝箱生成/开启 → 物资入库存
→ 小人消耗 tick → 需求状态更新 → 公路效率修正
→ 区域解锁 → 新天气权重更新 → 副本触发判定
→ 玩家参与副本 → 副本奖励结算 → 反哺车辆改装/物资
```

系统间全部通过事件通信，UI 只订阅刷新、不反向写入状态（SPEC 第 6 节）。

## 玩法模块

### 1. 开局选车（车辆）
三选一，选定后不可更换：
- **皮卡**：中庸均衡，宝箱概率 +5%。
- **厢式货车**：慢、油耗高、载货大，副本奖励 +10%。
- **摩托**：快、油耗低、载货小，里程宝箱阈值 −10%。

每辆车有 **2 条改装线、每条 2 级**，消耗 `parts`（零件）与蓝图碎片提升性能（Batch 3 接入）。

### 2. 公路推进与区域
- 车辆按 `速度 × 天气修正 × 小人状态修正` 自动累积里程（km）。
- 三个区域按里程解锁：**城郊 → 荒漠 → 冻原**，解锁不可逆；末区之后无限循环当前区域，里程继续累积。
- 区域解锁后天气权重表与副本池随区域变化。

### 3. 宝箱与物资
五种物资：`food` 食物、`water` 水、`medicine` 药品、`fuel` 燃料、`parts` 零件。
- **里程宝箱**：每推进一定距离自动开启（阈值随机，摩托更频繁）。
- **随机宝箱**：每 tick 按概率判定，受天气与车辆影响。
- **副本宝箱**：副本结算后生成，额外掉落**蓝图碎片**（用于改装）。
- 宝箱按配置权重掉落 1–3 种物资。所有随机使用确定性种子，读档后掉落序列可复现。

### 4. 小人需求（硬约束：永不死亡）
小人维持三条需求：`饥饿 / 口渴 / 生命`（0–100）。
- 每 tick 按速率下降；任一值 ≤0 时自动消耗对应库存补给（食物→饥饿、水→口渴、药品→生命）。
- **库存耗尽也不死亡**：需求钳制在 0，进入 `Weakened（虚弱）` 状态，仅使车速降至 0.7–0.9 倍（按虚弱程度插值，不降为 0）。
- 虚弱时消耗速率 ×1.3（生存压力上升）。三条需求全部恢复到 >60 后，60 秒内线性解除虚弱、速度恢复。
- 本游戏**没有死亡机制**。

### 5. 天气
按当前区域权重随机抽取，持续一段随机秒数，仅切换顶部小图标与场景色调，不弹模态窗：
- **晴天**：基准。
- **暴雨**：车速 ×0.85，宝箱概率 +10%。
- **沙暴**：车速 ×0.9，油耗 ×1.25，宝箱 +5%。
- **极寒**：车速 ×0.9，小人消耗 ×1.3。

### 6. 副本（可忽略）
- 冷却结束后按区域池随机触发，在窗口底部弹出**非模态提示**（一行文字 + 边缘高亮），不暂停公路、不夺焦点。
- **20 秒**内未点击则自动清除，视为忽略，公路照常推进。
- 点击后打开 60–90 秒轻量面板，含 2–3 个分支选项（如搜刮仓库 / 检查加油站 / 追击车队），选择即结算奖励并关闭。
- 奖励量级约等于同期基础挂机收益的 **2–3 倍** + 蓝图碎片。
- 设置项：`AutoIgnoreDungeons`（默认关，开启后不弹提示）、`PauseRoadDuringDungeon`（默认关，开启后副本期间暂停公路）。

### 7. 成就
10 个成就（按里程 / 开箱数 / 副本 / 区域 / 资源等条件触发），Batch 7 接入。

## 桌面窗口特性（Batch 5 起）
- **透明常驻**：无边框、半透明、置顶于桌面。
- **点击穿透**：全局快捷键（如 `Ctrl+Shift+D`）切换，透明区可点穿到桌面，UI 按钮区仍可交互。
- **托盘菜单**：最小化隐藏主窗口，托盘图标右键可显示/隐藏、暂停/继续、切换穿透、切换自动忽略副本、退出。
- 退出时自动恢复窗口样式，不残留。

---

## 四条硬架构约束（玩家也可理解为「设计承诺」）
1. **小人不可死亡**：最坏情况只是变慢，永远不会 Game Over。
2. **副本可忽略**：不点提示，20 秒后自动消失，进度零损失。
3. **后台 tick 不中断**：最小化或穿透时仍按真实时间推进收益。
4. **窗口穿透可恢复**：退出后系统窗口样式恢复正常。

---

## 美术与 UI 风格（SPEC 第 9 节）
- **高清像素风**：主相机 Pixel Perfect，精灵点过滤、无压缩，大尺寸绘制后下采样保证锐利。
- **配色鲜明 + 科技感**：暗底（#0B0E14）+ 霓虹青（#22D3EE）+ 琥珀（#FFB000），细 1px 霓虹描边、等宽科技字体，里程/需求用细长霓虹条形进度。
- 轻量动效，**禁用重粒子**（与性能目标冲突）。

## 如何运行（开发态）
1. 用 Unity Hub 打开本工程根目录（已含 `ProjectSettings` / `Packages`）。
2. `Assets/Scenes/Main.unity` 挂 `Bootstrapper` + `GameLoop`，并把 `DebugHud` 也挂上。
3. `Assets/Resources/` 右键 `Create → DesktopDoomsday → GameConfig` 填表（也可先不填，系统有兜底常量）。
4. 按 **Play**：公路自动推进；按 **`~`** 键开关调试面板，实时看里程/速度/小人/天气/物资/宝箱计数/FPS。

> 正式美术与玩法 UI（科技感 HUD、副本面板、离线报告）将在 Batch 6 落地，开发期请用 `DebugHud` 观测。
