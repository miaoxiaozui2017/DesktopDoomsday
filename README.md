# Desktop Doomsday · 桌面末世

> Windows 桌面常驻的**末日公路自动推进放置游戏**。开局选一辆车，车辆自动向前推进，宝箱开出物资，小人维持生存，随机副本可主动参与换取额外奖励——不参与也不影响基础推进。
>
> 它常驻在你的桌面上：半透明、可点击穿透、**默认仅浮于桌面背景之上（不遮挡其它应用）**，挂机时公路仍在跑。

---

## 一句话玩法

你不需要一直盯着它。选好车、让它上路，物资会自己进库存，小人会自己消耗与补给；偶尔桌面边缘弹出一行副本提示，想打就点、不想打就当它没出现。回归时看一眼离线报告，继续挂机。

---

## 核心循环

```
公路推进 tick → 里程累积 → 宝箱生成/开启 → 物资入库存
→ 小人消耗 tick → 需求状态更新 → 公路效率修正
→ 区域解锁 → 新天气权重更新 → 副本触发判定
→ 玩家参与副本 → 副本奖励结算 → 反哺车辆改装/物资
```

系统间全部通过事件通信，UI 只订阅刷新、不反向写入状态（SPEC 第 6 节）。

## 玩法模块

### 1. 开局选车（车辆）
三选一，选定后不可更换：
- **皮卡**：中庸均衡，宝箱概率 +5%。
- **厢式货车**：慢、油耗高、载货大，副本奖励 +10%。
- **摩托**：快、油耗低、载货小，里程宝箱阈值 −10%。

每辆车有 **2 条改装线、每条 2 级**，消耗 `parts`（零件）与蓝图碎片提升性能。在**车辆属性页（V 键）**可直接点「升级」按钮改装。

### 2. 公路推进与区域
- 车辆按 `速度 × 天气修正 × 小人状态修正` 自动累积里程（km）。
- 三个区域按里程解锁：**城郊 → 荒漠 → 冻原**，解锁不可逆；末区之后无限循环当前区域，里程继续累积。
- 区域解锁后天气权重表与副本池随区域变化。

### 3. 宝箱与物资
五种物资：`food` 食物、`water` 水、`medicine` 药品、`fuel` 燃料、`parts` 零件。
- **里程宝箱**：每推进约 3km 自动开启。
- **随机宝箱**：每 tick 按概率判定（`baseChestChance ≈ 0.014`），受天气与车辆影响。
- **副本宝箱**：副本结算后生成，额外掉落**蓝图碎片**（用于改装）。
- 宝箱按配置权重掉落 **1–2 种 × 1–2 单位**物资。**零件权重极低（4%）**，挂机很难攒到零件；蓝图碎片仅副本产出。想升级改装就多打副本。
- 所有随机使用确定性种子，读档后掉落序列可复现。

### 4. 开箱遇怪（新机制）
开宝箱时有概率遭遇怪物，扣小人三项属性各 10–20 点（**钳制 ≥1，永不致死**）。
- 概率 = **区域基础值** × **天气系数**：
  - 城郊 5% / 荒漠 15% / 冻原 25%
  - 晴天 ×0.4 / 暴雨 ×1.0 / 沙暴 ×1.3 / 极寒 ×1.2
- 前期城郊+晴天约 2%，几乎遇不到；后期冻原+沙暴可达 32%。
- 遇怪时状态面板上方弹红色警示条（4 秒），补给充足时可「一键补满」恢复。

### 5. 小人需求（硬约束：永不死亡）
小人维持三条需求：`饥饿 / 口渴 / 生命`（0–100）。
- 每 tick 按速率下降；任一值 ≤40 时自动消耗对应库存补给（食物→饥饿、水→口渴、药品→生命）。
- **库存耗尽也不死亡**：需求钳制在 0，进入 `Weakened（虚弱）` 状态，仅使车速降至 0.7–0.9 倍。
- 本游戏**没有死亡机制**。

### 6. 天气
按当前区域权重随机抽取，持续随机秒数：
- **晴天**：基准，遇怪概率最低。
- **暴雨**：车速 ×0.85，宝箱概率 +10%。
- **沙暴**：车速 ×0.9，油耗 ×1.25，遇怪 ×1.3。
- **极寒**：车速 ×0.9，小人消耗 ×1.3，遇怪 ×1.2。

### 7. 副本（可忽略）
- 冷却结束后按区域池随机触发，**在状态面板上方弹出琥珀色横幅**（副本名 + 倒计时 + 「查看」按钮），不暂停公路。
- **20 秒**内未点击则自动清除，视为忽略。
- 点「查看」后在横幅上方弹出分支面板，选分支即结算奖励（约同期挂机 2–3 倍 + 蓝图碎片）。
- 副本出现时窗口**自动转为可操作状态**（提前台 + 可点击），选完或超时后自动恢复穿透 + 底层。

### 8. 离线收益
- 上限 8 小时，按 **0.3 倍**速率推进里程与消耗（在线消耗不变，保持紧张感）。
- 离线期间不生成宝箱/副本，但有**路边拾荒**（每整小时 +4 食/+5 水/+2 药）抵消消耗后有少量正收益，离线回来物资不缺。
- 零件每 2 小时至多 +1（封顶 4），蓝图零产出。
- 回归后弹出离线报告面板（启动即弹，自动可点击，无需手动切穿透）。

### 9. 成就
10 个成就（按里程 / 开箱数 / 副本 / 区域等条件触发），在**成就图鉴（A 键）**查看，解锁时顶部弹吐司。

## 桌面窗口特性
> 注意：窗口层只在 **Windows 独立构建** 生效（编辑器 Play 仍是普通窗口）。

- **桌面宠物布局**：画面只渲染屏幕底部的路带 + 车辆 + 小人 + 宝箱，其余区域完全透明。车辆半透明（alpha 0.75），天气图标缩小半透明置于左上角。
- **透明常驻**：无边框 + `WS_EX_LAYERED` 分层透明（DWM 玻璃 + 相机 `RGBA(0,0,0,0)`），无黑边。
- **默认仅置桌面背景之上**：窗口发往 `HWND_BOTTOM`，不遮挡其它应用。需交互时面板自动提前台、关穿透，关闭后自动回底层。
- **点击穿透（默认开启）**：鼠标穿透到桌面。按 **`Ctrl+Shift+D`** 关闭穿透以操作 UI；副本/面板出现时自动关闭穿透。
- **帧率联动**：穿透态（挂机）**20fps** 省 CPU，交互态 **30fps** 流畅操作。由 `SetClickThrough` 状态变化守卫触发，无每帧开销。
- **焦点抢夺**：面板/副本/离线报告出现时自动 `ForceActivate`（AttachThreadInput 技巧绕过 Windows 防抢焦点限制），启动即弹的离线报告也能直接点。
- **退出方式**：状态面板「退出」按钮，或 UI 卡死时按 **`Alt+F4`** 强制退出。退出后窗口样式自动恢复。
- **托盘已移除**：不再在右下角显示托盘图标。

## 如何运行

1. 用 Unity Hub 打开本工程（Unity 2022.3 LTS）。
2. 打开 `Assets/Scenes/Main.unity`。
3. **首次必须**：Unity 菜单 → `DesktopDoomsday` → `创建默认 GameConfig`（生成 `Assets/Resources/GameConfig.asset`，否则系统走兜底默认值，无成就/副本配置/怪物字段）。**更新数值后需重新执行并选「覆盖」**。
4. `File → Build Settings → PC, Mac & Linux Standalone → Windows → Build And Run` 验证桌面宠物终态。
5. 编辑器 Play 可快速验收数值与 UI 逻辑（窗口层不生效，其余一致）。
6. 场景如有残留 Missing Script 警告：Unity 菜单 → `DesktopDoomsday` → `清理 Missing Script 组件`，一键扫描移除。

> 正式 UI 全部走 IMGUI（`OnGUI`），不依赖 `UnityEngine.UI` 程序集。中文字体 `msyh.ttc` 已内嵌于 `Assets/Resources/Fonts/`。

## 四条硬架构约束（设计承诺）
1. **小人不可死亡**：最坏情况只是变慢，永远不会 Game Over。
2. **副本可忽略**：不点提示，20 秒后自动消失，进度零损失。
3. **后台 tick 不中断**：最小化或穿透时仍按真实时间推进收益。
4. **窗口穿透可恢复**：退出后系统窗口样式恢复正常。
